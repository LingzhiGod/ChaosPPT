# PPT 通用设计原则

用于规划、设计和交付前审阅，随 ChaosPPT 默认生效。用户提供的品牌、参考稿、演示场景和受众要求决定具体视觉方向；具体配色与组件实现保存在项目主题或可替换主题包中。

## 1. 全稿共享一个视觉系统

扩展页面前，先在 `theme.css` 与母版中明确：

- 字体角色：标题、正文、数字、代码及对应字重、字号、行距。
- 颜色角色：背景、主文字、次文字、强调、状态和数据系列。
- 布局基础：画布、安全边距、内容起点、网格、间距阶梯与页脚位置。
- 图形语言：线条粗细、箭头、图标风格、圆角、阴影和图片处理。
- 数据语言：系列颜色、图例顺序、标签格式、数值精度、单位和日期格式。

共用样式集中声明，页面从同一套变量和组件取值。例如图表与正文都从 CSS 变量读取颜色，避免各页面脚本各自分配调色板。运行时已有 `--font-body`、`--font-display`、`--bg`、`--fg`、`--muted`、`--accent`、`--space`、`--safe`；可按需添加字号和系列变量。

同一个产品、渠道或状态在整份 PPT 中保持相同的颜色和名称。语义色的含义由品牌和受众场景确定，避免红色在不同页分别表示增长、失败和普通系列。分类色、连续数值色阶与正负分歧色阶分别按对应关系使用。

封面、章节页和结尾页可以切换深浅背景，但作为主题内的明确变体处理，保留字体体系、品牌色、构图逻辑及数据语义。内容布局随页面目标变化，主题保持连贯。品牌资产保持比例，按提供的版本和使用要求呈现。

## 2. 叙事与视觉传达

- 每页先定义受众要理解什么、比较什么或做什么决定，再安排内容。
- 一页围绕一个主要信息目标，可包含多个互相支持的证据；复杂议题按阅读顺序拆解。
- 标题清楚命名主题；有充分证据的结果页可以用结论式标题。标题与图表表达同一个信息目标。
- 把最重要的证据放在视觉中心，通过位置、面积、字重或强调色建立主次。
- 图片解释对象或场景，示意图解释结构和机制，图表解释数据关系，表格支持精确查阅。小量事实可直接使用文字或关键数字。
- 装饰应有助于品牌识别、阅读分组或强调重点。每个额外元素都应有明确的表达作用。

## 3. 布局、层级与节奏

执行对齐、对比、重复、邻近与留白原则：

- 用网格或共同基线对齐标题、图表、正文和注释；相关内容靠近，无关内容用空间分组。
- 用字号、字重、位置和颜色共同表达层级，建立清晰的主视觉与阅读路径。
- 保留安全边距与内容组间呼吸空间；截图预览时确认阅读顺序自然。
- 正文过多、系列过密或标签拥挤时，精简措辞、分组、改为小多图或拆页，再调整局部间距。
- 保持封面、内容、数据、章节与结尾之间的节奏；相似内容共用结构，不同任务采用适合的构图。
- 正文、坐标标签和必要注释在实际演示尺寸下可读。避免把关键信息压入细小页脚。

字号可从与画布适配的层级起步。对默认 1600×900 画布，标题约 56–76 CSS px、正文约 28–36 px、图表标签约 20–24 px 可作为初始参考；依据字体、投影距离、受众和内容调整。这些是项目设计起点，并非所有 PPT 的固定标准或渲染器阈值。

## 4. 按问题与数据选择图、表

先判断分析任务，再核对数据是否支持这种表达。以下是优先选择与适用条件，存在多个有效选项时以易读、准确和受众熟悉度决定。

| 要表达的问题 | 优先图形 | 选择条件与注意事项 |
| --- | --- | --- |
| 哪些类别更多、排名如何 | 水平条形图、柱状图、点图 | 长名称优先水平布局；排名按数值排序，自然顺序的类别保留顺序。长度编码的条形/柱形从零开始，负数围绕零线展开。 |
| 随时间怎样变化 | 折线图；少量离散时点可用柱图 | 时间按真实间隔排列。缺测点留空或断线；插值与预测有依据且区别呈现。系列拥挤时用直接标签、重点系列或同尺度小多图。 |
| 总体由哪些部分组成 | 堆叠条形图；单个整体且类别很少时可用饼/环图 | 类别互斥、数值非负、同一口径并构成整体。相近占比需精确比较时优先条形，避免 3D 和分离扇区。 |
| 多个群体的构成有何不同 | 100% 堆叠条形图 | 每组整体归一为 100%，保留统一系列顺序与颜色；若比较绝对规模，选普通堆叠图或另示总量。 |
| 样本如何分布、是否偏斜或有离群 | 直方图、箱线图、点分布图 | 有原始样本或足够统计量；分箱和分位数有依据。只有均值时呈现均值，不推造分布。 |
| 两个数值变量有什么关系 | 散点图 | 每个点来自同一观测的成对数据，标清单位；根据证据描述关联，避免将关联解释为因果。 |
| 起点到终点由哪些增减构成 | 瀑布图 | 存在可核对的起点、增减项和终点；项目相加应与终值一致。 |
| 实际相对目标偏差多少 | 并列柱图、哑铃图、目标标记图 | 同单位、同周期；需要精确金额、多个口径和计算结果时，使用表格或表图组合。 |
| 哪些组合高、低或异常 | 热力图 | 两个分类/有序维度与一个可比较数值，颜色范围与图例统一；重要值补文字，避免仅凭颜色猜数。 |
| 各阶段流失和转化怎样 | 阶段条形图、漏斗图 | 同一口径下的顺序阶段，人数/事件可衔接；标明转化率的分母。不相关指标用普通比较图。 |
| 谁流向谁、流量如何分配 | 桑基图 | 有真实的来源、去向和流量关系，节点与流量口径可核对；简单路径优先流程图。 |
| 流程、依赖或层级怎样组织 | 流程图、泳道图、树形图、结构图 | 箭头有明确方向和含义；泳道表达参与角色，层级树表达隶属关系。 |
| 需要逐项查数或比较多个属性 | 表格 | 有清晰表头、单位和行列关系；数值右对齐、精度一致，重点行或差异项适度强调，长表拆分或放附录。 |
| 单个或少量指标是什么 | 关键数字配简短解释 | 数值同时给单位、时间与必要基准；没有比较任务时保持简洁。 |
| 地理位置是否解释差异 | 地图；排名任务可用条形图 | 地理关系本身有意义时使用地图；绝对量与按人口/面积标准化的比率区分，标明口径。 |
| 估计值有多大不确定性 | 带区间的点图、误差线、置信带 | 已提供或有依据地计算区间，注明区间含义；避免用虚构误差线装饰图形。 |

## 5. 数据编码与准确性

- 单位、币种、时间范围、样本和百分比分母明确；跨页比较采用一致口径，口径变化在相关内容中清楚标注。
- 同一实体跨页保持配色、名称和图例顺序。并排比较的图使用相同尺度；独立尺度有必要时明确展示差异。
- 条形图以零基线表达长度，负值保留方向；折线图可按问题采用适当范围，轴域清楚，避免放大小幅波动造成误读。
- 缺失值与零值分开。实际、预测、目标等状态用明确标签或线型区分。
- 金额、数量、占比和百分比变化区分；从 20% 到 25% 是增加 5 个百分点，相对增长为 25%。
- 分类使用区分色，连续量使用连续色阶，围绕有意义基准的正负偏差使用分歧色阶。颜色以标签、线型或形状辅助识别。
- 图例、标签和必要注释帮助理解，优先直接标注关键系列；避免密集的全点标值和多重坐标轴带来的阅读负担。
- 图的高度、长度、面积和颜色强度与数值含义一致，避免装饰性透视或不成比例图形改变感知。

## 6. 可读性与包容性

- 图像背景上的文字保持稳定对比，需要时加入纯色承载区。
- 普通文本可采用至少 4.5:1 的对比目标；符合 WCAG 大文本定义的文字可采用 3:1。数值是设计检查依据，字体、背景纹理与实际观看环境仍需审阅。
- 用文字、线型、形状等共同传达状态和数据系列，颜色承担辅助区分作用。
- 图片、图表和媒体在 HTML 中提供有意义的名称或说明，讲稿可保留结构化数据与解释；以实际输出格式核对信息是否仍可获取。
- 表格标题与单位明确，阅读顺序自然；动效和媒体服务表达，静态画面仍能理解本页重点。

## 7. 设计与交付审阅

规划每页时，明确“目的 → 证据 → 视觉形式 → 重点”。可将选型理由写入页面 `purpose` 或讲者备注；共享主题与变体的具体值保存在项目文件。

渲染后进行两种审阅：

1. **逐页看**：主次是否清楚，文字和标签是否可读，图形是否适合问题，轴域/分母/单位/缺测是否正确，注释是否有信息价值。
2. **整稿看**：把截图并排或缩小查看，检查字体、配色、间距、图例、语义色和页脚是否漂移，深浅变体是否仍属于同一主题，内容密度和章节节奏是否协调。

对发现的问题修改后重看受影响页面；共享主题修改影响全稿。此审阅与 [文案约束](copy-style.md) 一起执行，避免为验证过程再生成面向受众的免责小字。`inspect` 提供布局与资源诊断，设计原则由 Agent 在规划和视觉审阅时执行。
