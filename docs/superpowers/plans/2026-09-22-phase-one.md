# ChaosPPT Phase One Implementation Plan

**Goal:** Ship a local HTML presentation engine and reusable Agent Skill with real, verified PDF/image-PPTX output.

**Architecture:** Browser-native fixed-size slides are the source of truth. A loopback HTTP server injects theme, master and lifecycle helpers; Playwright measures/renders slides; pdf-lib and PptxGenJS package outputs. The same server drives a scaled keyboard-navigable preview.

**Tech Stack:** Node.js ES modules, Playwright Chromium, Zod, pdf-lib, PptxGenJS, Node test runner.

## Files and boundaries
- `src/project.js`: strict manifest validation, safe project path resolution, starter creation.
- `src/server.js`: loopback routes, page assembly, preview and static assets.
- `src/browser-runtime.js`: asynchronous ready contract, fonts/images/layout readiness and deterministic capture.
- `src/diagnostics.js`: browser-side element bounds and overflow measurements.
- `src/renderer.js`: Chromium lifecycle, reports, PNG/PDF/PPTX build and output verification.
- `src/cli.js`: explicit command/argument validation and JSON results.
- `assets/runtime.css`, `assets/player.html`: slide primitives and live preview.
- `templates/starter/`: runnable Chinese multi-page sample with local font and asynchronous SVG/Canvas evidence.
- `skills/chaosppt/`: portable skill instructions, API reference, runner.
- `tests/`: schema, server boundary, diagnostics and export integration tests.

## Acceptance commands
```sh
npm install
npx playwright install chromium
npm test
node src/cli.js init ./examples/demo
node src/cli.js inspect ./examples/demo --json
node src/cli.js render ./examples/demo
node src/cli.js export ./examples/demo --format pdf,pptx
node src/cli.js verify ./examples/demo
```

Acceptance: three example slides render without diagnostic errors; PDF/PPTX/PNG share page count/order/aspect; bad fixtures emit nonzero status with actionable JSON; missing resources and unresolved asynchronous work never silently pass.
