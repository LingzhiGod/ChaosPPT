# 动画示例设计规格

受众：检验 ChaosPPT 动画映射的使用者；1600×900 屏幕演示。
美学：清晰、克制、统一浅色背景，不通过深浅主题跳转制造变化。
背景 #F4F3EB，标题/正文 #18352C，次要文字 #617168，强调 #D96E42，系列色 #4E78BD / #709743。
字体统一 Noto Sans SC；H1 64px/700/1.25，H2 36px/700/1.35，正文 28px/400/1.5，标签 20px/400/1.4，页脚16px/400/1.4。
四页使用同一网格、安全边距72px、圆角12px。动画采用线性时序，进入500–800ms，跨页Morph900ms。动效用于强调顺序、条形展开和保持同一组件身份；不使用无限循环或装饰性抖动。
